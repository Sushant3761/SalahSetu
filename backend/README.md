# SalahSetu Node.js Backend

## Overview
SalahSetu Node.js + Express backend foundation providing REST API endpoints to proxy requests between clients and the Python AI Service.

## API Endpoints

- `GET /api/health` — Liveness health check
- `POST /api/v1/legal/query` — Legal intelligence query endpoint

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Start production server
npm start
```
