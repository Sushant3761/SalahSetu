# SalahSetu

## Project Purpose
SalahSetu is an official-source AI-powered citizen legal and land intelligence platform.

## Current Development Stage
Project initialization

## Major Modules
1. Legal document understanding
2. Document upload and analysis
3. Official-source RAG with citations
4. Land and plot information
5. Cadastral/locality map intelligence
6. Land-use and construction/development planning intelligence
7. Land acquisition intelligence
8. Deadline and reminder tracking
9. Action and next-step guidance

## Planned Technology Stack
- React + Vite + JavaScript
- Node.js + Express
- MySQL
- Python
- RAG
- Embeddings
- FAISS
- LLM integration
